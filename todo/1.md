## 2. 功能需求

### 2.1 范围迭代语法 (Range-based For Loop)

**需求描述**：支持 Haxe 风格的范围迭代语法

**语法规范**：
```typescript
// 基础范围迭代
for (i in 0...10) {
  console.log(i); // 输出 0 到 9
}

// 带步长的迭代
for (i in (0...100).stepBy(5)) {
  console.log(i); // 输出 0, 5, 10, ..., 95
}

// 包含上界的迭代（可选） 不要支持
// for (i in 0...=10) {
//   console.log(i); // 输出 0 到 10
// }
```

**技术要求**：
- 编译器需在 AST 解析阶段识别 `in x...y` 语法
- 转译为标准的 `for` 循环或 `Array.from` + `forEach`
- `stepBy` 方法需返回可迭代对象
- 支持负数和倒序迭代

**输出示例**：
```javascript
// 转译后
for (let i = 0; i < 10; i++) {
  console.log(i);
}
```

enum Result<T, E> {
  Ok(value: T),

enum Option<T> {
  Some(value: T),
  None

// 使用示例
const result: Result<number, string> = Result.Ok(42);

**技术要求**：

**运行时实现**：

  }

### 2.3 属性访问器 (Property Accessors)

**需求描述**：支持 Haxe 风格的 getter/setter 声明

**语法规范**：
```typescript
class Rectangle {
  private _width: number = 0;
  private _height: number = 0;

  // Haxe 风格
  public var width(get, set): number;
  public var height(get, set): number;
  public var area(get, never): number;

  function get_width(): number {
    return this._width;
  }

  function set_width(value: number): number {
    return this._width = Math.max(0, value);
  }

  function get_area(): number {
    return this._width * this._height;
  }
}
```

**访问权限修饰符**：
- `(get, set)` - 可读写
- `(get, never)` - 只读
- `(never, set)` - 只写
- `(default, default)` - 公开字段
- `(default, null)` - 可初始化后只读

**技术要求**：
- 编译为 ES5 getter/setter 或私有字段
- 支持访问权限控制
- 类型推断支持

### 2.5 抽象类型 (Abstract Types)

**需求描述**：零成本包装类型，编译时类型安全

**语法规范**：
```typescript
abstract Meter(number) {
  inline function new(value: number) {
    this = value;
  }

  @:op(A + B)
  static function add(a: Meter, b: Meter): Meter {
    return new Meter(a.toNumber() + b.toNumber());
  }

  public inline function toNumber(): number {
    return this;
  }
}

// 使用
const distance: Meter = new Meter(100);
const total = distance + new Meter(50); // 类型安全
```

**关键特性**：
- 运行时零开销（编译后为基础类型）
- 编译时类型区分
- 支持运算符重载
- 隐式/显式转换控制

**技术要求**：
- 使用 branded types 实现
- 内联函数完全消除包装
- 运算符重载通过方法调用实现

### 2.7 枚举作为代数数据类型 (Enums as ADTs)

**需求描述**：完整的 ADT 支持（已在 2.2 中部分覆盖）

**扩展要求**：
```typescript
enum BinaryTree<T> {
  Leaf,
  Node(left: BinaryTree<T>, value: T, right: BinaryTree<T>)
}

// 递归处理
function depth<T>(tree: BinaryTree<T>): number {
  return match (tree) {
    BinaryTree.Leaf => 0,
    BinaryTree.Node(left, _, right) => 
      1 + Math.max(depth(left), depth(right))
  };
}
```

**技术要求**：
- 支持递归类型定义
- 与模式匹配深度集成
- 优化的内存表示

### 2.9 内联函数 (Inline Functions)

**需求描述**：编译时函数内联优化

**语法规范**：
```typescript
inline function square(x: number): number {
  return x * x;
}

inline function clamp(value: number, min: number, max: number): number {
  return Math.min(Math.max(value, min), max);
}

// 调用
const result = square(5) + clamp(10, 0, 100);

// 编译后
const result = 5 * 5 + Math.min(Math.max(10, 0), 100);
```

**技术要求**：
- 在 AST 转换阶段内联
- 支持泛型函数内联
- 避免副作用时才内联
- 编译选项控制内联策略
- 递归调用不内联

**限制条件**：
- 函数体不超过配置的行数
- 不包含复杂控制流
- 参数无副作用

### 2.10 静态扩展 (Static Extensions)

**需求描述**：为现有类型添加方法而不修改原型

**语法规范**：
```typescript
// 定义扩展
static extension StringTools {
  static function reverse(str: string): string {
    return str.split('').reverse().join('');
  }

  static function capitalize(str: string): string {
    return str.charAt(0).toUpperCase() + str.slice(1);
  }
}

// 使用（编译时转换）
using StringTools;

const reversed = "hello".reverse(); // ✅
const capped = "world".capitalize(); // ✅
```

**技术要求**：
- `using` 语句导入扩展
- 作用域限制（文件/块级）
- 编译为静态方法调用：`StringTools.reverse("hello")`
- 支持泛型扩展
- 类型推断保持

**与 TypeScript 现有特性的区别**：
| 特性 | 静态扩展 | 原型扩展 |
|------|----------|----------|
| 运行时影响 | 无 | 修改全局原型 |
| 作用域 | 局部 | 全局 |
| 性能 | 无开销 | 原型链查找 |
